# Farpost-Telegram Parser
[[English version]](README.md)  
Расширение для Chrome, которое автоматически обновляет страницу Farpost и отправляет сообщение в Telegram, если появляется новое объявление.  
Работает только на страницах «Подписки» с новыми объявлениями, отсортированными по дате.

# Инструкция
Чтобы использовать расширение, выполните следующие шаги:  

### Установка расширения Chrome из ZIP-файла
1. Распакуйте ZIP-файл в папку на вашем компьютере.
2. Откройте Chrome и перейдите по адресу `chrome://extensions`.
3. Включите режим разработчика в правом верхнем углу.
4. Нажмите `Загрузить распакованное расширение`.
5. Выберите папку с распакованным расширением (папку, содержащую manifest.json).
6. Расширение появится в Chrome и будет готово к использованию.

### Создание Telegram-бота
1. Откройте Telegram и найдите `@BotFather`.
2. Начните чат с BotFather и отправьте `/newbot`.
3. Введите имя для вашего бота, например: My Test Bot.
4. Выберите имя пользователя (username) для вашего бота.
5. BotFather создаст бота и отправит вам HTTP API `токен`.
6. Скопируйте и надёжно сохраните этот токен. Не публикуйте его, так как любой, у кого есть токен, может управлять вашим ботом.

### Получение вашего ID пользователя в Telegram
1. Откройте Telegram и найдите `@userinfobot`.
2. Запустите бота, нажав Start.
3. Он ответит сообщением с информацией, включая ваш числовой User ID.

### Настройка расширения
1. Откройте расширение в правом верхнем углу (должно появиться окно, как на скриншотах).  
2. Скопируйте токен бота в поле `BotID`, а ваш ID в поле `ChatID`.  
3. Настройте остальные параметры по своему усмотрению и обязательно нажмите «Сохранить».  

### Завершающие шаги
1. Откройте страницу подписок на Farpost.  
2. В поле «Состояние вкладки» переключите статус с `«ВЫКЛ»` на `«ВКЛ»`.

✅ Готово! Когда появятся новые объявления, вы получите сообщение в Telegram.
